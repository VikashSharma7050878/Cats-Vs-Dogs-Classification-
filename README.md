# Cats vs Dogs Classification

## Project Overview

This project uses Deep Learning and Convolutional Neural Networks (CNNs) to classify images into two categories: Cats and Dogs.

## Technologies Used

* Python
* TensorFlow / Keras
* NumPy
* Matplotlib
* CNN (Convolutional Neural Network)

## Objective

To train a deep learning model that can identify whether an input image contains a cat or a dog.

## Project Status

Currently in development.
